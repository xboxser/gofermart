[Документация](./doc/readme.md)

Реализованно
 - POST /api/user/register — регистрация пользователя;
 - POST /api/user/login — аутентификация пользователя;
 - POST /api/user/orders — загрузка пользователем номера заказа для расчёта;
 - GET /api/user/orders — получение списка загруженных пользователем номеров заказов, статусов их обработки и информации о начислениях;
 - GET /api/user/balance — получение текущего баланса счёта баллов лояльности пользователя;

Реализованно но требует доработки
 - GET /api/orders/{number} — получение информации о расчёте начислений баллов лояльности.

 - - Доработаю: Если получаем 429 ответ, Горутина будет ожидать N время и повторять запрос
 - - Доработаю: При получение ошибки по заказу, он будет обратно возвращаться в очередь
 - - Доработаю: В генератор будет запоминать номера заказов, которые уже были.

В работе 
 - POST /api/user/balance/withdraw — запрос на списание баллов с накопительного счёта в счёт оплаты нового заказа;
 - GET /api/user/withdrawals — получение информации о выводе средств с накопительного счёта пользователем.
